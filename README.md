# Andrea Zollini

Full-stack developer. I build local-first developer tools: small programs that run on your machine, keep your data, and work for any coding agent.

## Featured

| Project | What it is |
|---|---|
| [oi.c](https://github.com/zo-ll/oi.c) | C11 library and CLI for streaming OpenAI-compatible chat and durable agent sessions. One single-threaded reactor. CI runs ASAN, UBSAN, TSAN, valgrind, and a fuzz job. |
| [tide](https://github.com/zo-ll/tide) | Minimal async terminal toolkit for Go TUI apps. Standard library only. `go get github.com/zo-ll/tide` |
| [termdeck](https://github.com/zo-ll/termdeck) | Rust terminal deck: one master pane, a live preview stack, and a control API that agents call. |
| [filo](https://github.com/zo-ll/filo) | Multi-agent protocol for building software: coordinator, worktree workers, independent critics, engine-run checks. Plain bash. |
| [lkj](https://github.com/zo-ll/lkj) | Local speech-to-text bridge for agents. Go binary, whisper.cpp backend, no Python. |
| [skills](https://github.com/zo-ll/skills) | Agent skills for coding agents: code review, verification, reports, learning. |
